# Expense-Tracker
Expense Tracker Mobile App:
Overview:
Expense Tracker is an Android app developed in Java using Android Studio. It helps users manage daily expenses by allowing them to add, view, and delete expenses. Data is stored locally using SQLite, so it works offline.

Features:
-User login and registration
-Add new expenses (title, amount, category, date, notes)
-View all expenses on dashboard
-Delete expenses with long-press
-Offline storage with SQLite

Technologies:
-Android Studio
-Java
-XML for UI
-SQLite database

Installation:
Clone the repository:
git clone https://github.com/MaryamIkram176/expense-tracker.git
-Open in Android Studio
-Build and run on an Android device or emulator

Usage:
-Register or login
-Add new expenses
-View or delete expenses on the dashboard
